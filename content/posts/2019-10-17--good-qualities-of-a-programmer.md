As a Junior dev having 2 years of experience. I have learned and followed some of the experience which are shared by my mentor. I think it has really helped me a lot. Thought of sharing a few things here.

1. Var i=0 to var index = 0, is the first level of improvement. I personally believe this a lot. Because I find hard to read when someone has written unintended code with a poor naming convention.

2. If anyone choose their career as programming, then they should have a mindset like (dev as a career is lifelong learning). We have to update ourself frequently.

3. We should take care of our code as a child. We should avoid polluting the global space.

4. Any new implementation, please don't hit the keyboard instantly. At least spend time for thinking of how to solve this problem. Spend time for sequence diagram, naming convention (I used to spend major time on this area).

5. Build a habit of reading others' code. Reading other's code will make you think wisely. Don't hesitate to read, moreover you are not copying.

6. Follow people who has the same mindset like you (or) who is good at things which you are doing.
Learn how to debug your code by using your IDE (or) using any of your dev tools. This will save your time.

Front-end developers should remember using an alert statement had became an obsolete technique.

These are the few important things, a programmer should follow to become a better programmer.
If you guys find any other things, please let me know in the comments!
